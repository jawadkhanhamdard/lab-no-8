## Lab Objectives
- Understand how to define and use structures in C++.
- Store and access multiple related data items using a single structure.
- Use the member access operator (.) to read and write structure members.

## Tasks
| File | Description |
|---|---|
| `task1-student.cpp` | Student structure (name, roll, gpa): input and display. |
| `task2-laptop.cpp` | Laptop structure (brand, ram, price): input and display specifications. |
| `task3-rectangle.cpp` | Rectangle structure (length, width): calculate area and perimeter. |
| `task4-gpa-comparison.cpp` | Input two students, show the one with the higher GPA, or print "Both students have equal GPA". |

## How to Compile and Run
```bash
g++ task1-student.cpp -o task1
./task1          # on Windows PowerShell: .\task1.exe

g++ task2-laptop.cpp -o task2
g++ task3-rectangle.cpp -o task3
g++ task4-gpa-comparison.cpp -o task4
```
Names are read with `cin`, so enter them as a single word (for example `Ali`).
